## SEO and Google Search Console
The production deployment uses `https://milkmitra.vercel.app/` as its canonical URL. `public/robots.txt` and `public/sitemap.xml` are published at the site root. The Google Search Console HTML verification file is copied from `public/` to the deployment root, so it can be checked at `https://milkmitra.vercel.app/googlea15bb2e786869302.html`. Deploy these changes, verify that URL is reachable, then complete verification in Google Search Console and submit `https://milkmitra.vercel.app/sitemap.xml`.
